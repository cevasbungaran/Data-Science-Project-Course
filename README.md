# Data Science Project Course
- There is some place of worhsip that is dominated by specific ethnic.
- Many restaurant have their own specific food, such as chinese food, indonesian food, and many more.
- Person's name usually symbolize their ethnicity, either from their family name or their first name.
- The goal of this project is to analyze ethnic distribution from restaurant, place of worship, and person's name.
- Build prediction model to predict person's ethnic is sundanese or not based on their name.

## Analysis Brief
- Gather data for person's name, place of worship, and restaurant.
- Analyzing name or pattern that often appear for specific ethnic.
- Using Levenshtein Ratio to measure the similarity distance of a name from a survey with sample data.
- Using K-Nearest Neighbors, Naïve Bayes, Decision Tree, and Random Forest to build a model.
- Choosing the best model for predicting ethnicity.

## Data
- The data for place of worship and restaurant was collected using Wikimapia.
- Gather the data for person's name from questioner and the head of neighborhood unit.
